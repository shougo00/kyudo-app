# 正規連の変更履歴を手動で削除する

システム管理 → 正規連の変更履歴にある「1か月より古い履歴を削除」ボタンから実行します。
自動削除・定期実行はありません。Windowsの専用タスクも登録していません。

- システム管理者（KANRI）のみ実行できます。
- 削除前に対象の期限と件数を表示し、確認を求めます。
- 現在の絞り込み条件に関係なく、全グループの古い変更履歴が対象です。
- 練習日ではなく、操作日時で判定します。昔の記録を最近編集した履歴は残ります。
- 1か月の期限ちょうどは残します。月末は前月の最終日に合わせます。
- 画面を開いてから時間が経っても、画面に表示した期限より新しい履歴は削除しません。
- 期限を改ざんしても、直近1か月分は削除しません。
- 最大1,000件ずつ削除し、的中記録（records・shots）やユーザー情報には触れません。
